pos.js
// Global variable — lives in the system
let accountBalance = 20000;

// Main function — takes a callback
function checkAccount(pin, amount, callback) {
  if (pin !== 1234) {
    callback("error", "Incorrect PIN");
    return;
  }
  if (amount <= accountBalance) {
    accountBalance -= amount;
    callback("success", amount);
  } else {
    callback("failure", "Insufficient funds");
  }
}

// Callback — handles the result
function transactionResult(status, data) {
  if (status === "success") {
    // Update DOM with result
    screen.textContent = "Withdrawal complete!";
  }
}

// Event listener triggers it all
btn.addEventListener("click", function() {
  checkAccount(pin, amount, transactionResult);
});

Learning Path

How everything connects

Every concept builds on the last. This is the order that makes sense.

Functions & Callbacks

Functions are reusable machines. Callbacks are functions passed into other functions to run later — the foundation of everything async.

Scope & Closures

Scope controls where variables live. Closures let inner functions remember outer variables even after the outer function is gone.

Arrays & Array Methods

Arrays hold lists. forEach, map, filter and find use callbacks to process every item — connecting directly back to functions.

Objects

Objects group related data together as key-value pairs. Methods are functions inside objects. this refers to the current object.
